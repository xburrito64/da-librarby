A small fix for anime movies AniList doesn't have.

### Fixed

- **Anime movies missing from AniList**, like *Attack on Titan: THE LAST ATTACK*, now get their name, description, poster, cast and everything else from TMDB instead of staying blank. Before, anime movies were only ever looked up on AniList.
- **Fix match** for an anime movie lists TMDB's movies below AniList's, marked **TMDB**, so you can pick the right one even when AniList doesn't have it. Picking an AniList entry again (or "Let the app decide") goes back to AniList.

Anime movies AniList found nothing for are looked up on TMDB once after updating.

### Installing

Download `Da.Librarby_0.5.4_x64-setup.exe` below and run it. It updates an existing installation and keeps your library, watch history and settings. Windows may say the publisher is unknown because the installer isn't signed: click **More info → Run anyway**.

New here? Add your folders in the app, then follow Settings → Online info to get a free TMDB key for show and movie info (anime works without one).

Windows 10/11, 64-bit.
