A small fix for 0.3.0.

### Fixes

- **Seek bar previews** went missing every other time you opened a video (only the time and chapter showed when pointing at the seek bar). They now show every time.

### Installing

Download `Da.Librarby_0.3.1_x64-setup.exe` below and run it. It updates an existing installation and keeps your library, watch history and settings. Windows may say the publisher is unknown because the installer isn't signed: click **More info → Run anyway**.

Windows 10/11, 64-bit.
